# One interpretation rule for package quantities

Herman now has a tested calculation component that distinguishes supported historical conversions, reviewed interpretations and future selections. Missing historical support withholds the numeric result. It also keeps a bounded list of the source contexts needing later capture and review.

The related pure calculation suite passed 99 tests. Connecting this component to the live backend remains the next step. Database checks and GitHub publishing remain pending as requested; this is not a completed release.
