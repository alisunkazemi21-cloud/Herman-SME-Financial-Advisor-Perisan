# C11 technical report: general request-only Quick context

The existing Quick context/draft endpoints accept question-only requests, optional notes and up to eight text excerpts, optional dated financial figures and optional legacy inventory data. No migration or persistent Quick tables were added. Authentication remains at the API boundary; the context function receives no database/service object and neither retrieves nor stores business history.

Financial inputs use 17 permitted field names, explicit IRR/IRT units and unique source references. Duplicate fields, missing sources, invalid signs, inconsistent supplied balances and precision/conversion overflow fail validation. Twelve supported metrics return available, missing-input or undefined status with exact source locators. The ten ratio definitions are shared with the earlier pipeline, whose result shape/context behavior is preserved. Quick conversion/calculation uses a fixed 60-significant-digit, half-even Decimal context; nonterminating division is rounded at that precision.

The normalized request and expanded response are each bounded to 64 KiB. No source or reference is truncated. Excerpt text is preserved and SHA-256 identified but remains unverified. The local Quick prompt supports conceptual explanation and clarification while restricting numeric conclusions to supplied calculations; no tools, database selectors or provider configuration are accepted from the request. All model prose remains an unverified draft. Binary document upload and actual model quality remain open.

The focused suite passed 71 tests, including 31 new cases. The full PostgreSQL run passed **226**, skipped the one real-OCR fixture test and reported 30 non-failing warnings in 198.42 seconds. Tests check independent numeric expectations, legacy ratios, precision/rounding, missing/undefined states, source receipts, bounds, authentication, no business transactions, no request carryover and prompt/transport isolation. Ruff and whitespace checks passed; the Persian example was executed successfully. See [validation](../research/VALIDATION.md).

Graphify recorded 990 nodes, 3,089 relationships and 58 communities. The prompt-only module has no AST symbols, and token savings remain unmeasured. The contract, run, chapter, narrative and [progress map](../research/PROGRESS.md) are synchronized; the product UI remains deferred.
