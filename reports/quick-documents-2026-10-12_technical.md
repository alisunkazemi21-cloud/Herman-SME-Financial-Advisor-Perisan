# C15 technical report: temporary Quick documents

The new raw-byte extraction route accepts CSV/XLSX, PDF and supported single-frame images. It returns bounded text sources with source-byte/text hashes and row/page/image character references. Existing Quick JSON routes accept this optional origin metadata, validate text/span consistency and preserve explicit financial input requirements. All handled Quick validation errors are sanitized and marked no-store.

The parser has no database or business-service dependency. Authentication runs in the parent before and after extraction; temporary files use generated names, a restricted environment and request-local scratch space. The child cannot start parsing until containment is established. Windows Job Objects and POSIX process groups terminate descendants on completion/failure; cancellation retains the slot until bounded worker cleanup finishes. The optional EasyOCR model path is resolved by the parent without forwarding credentials or home-directory environment variables.

The full PostgreSQL suite passed 362 tests with one real-OCR skip in 421.28 seconds. After the final locator-whitespace fix and one added case, the combined Quick/intake/draft suite passed 86 tests, including all 50 intake cases, in 24.96 seconds. Ruff and whitespace checks passed. Tests cover real CSV/XLSX/text-PDF subprocesses, all supported image adapters with controlled OCR replies, source/chunk reconstruction, metadata validation, XLSX array formulas, undersized dimensions and distinct whitespace-bearing sheet names, table/archive/page/pixel/text/reference bounds, missing engine/language/model data, actual process-tree cleanup, failed Windows containment, receive timeout, cancellation, credential revocation, generic errors and absence of business transactions or request carryover.

No migration is required. The persistent extraction queue and immutable business evidence remain separate. OCR accuracy, local-model quality, native-PDF visual completeness, semantic financial mapping, official accounting interpretation, operational restore and representative 1,000-business capacity remain unverified. The visible product UI is unchanged. See [the exact intake contract](../research/QUICK_DOCUMENTS.md) and [run evidence](../runs/quick-documents-2026-10-12/README.md).
