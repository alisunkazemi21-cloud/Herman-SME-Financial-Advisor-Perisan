# Herman can report unavailable backend dependencies

The new readiness endpoint checks whether the backend can reach required database features and use its evidence directory. Monitoring can distinguish an available dependency path from a running process. Failures expose a generic status rather than private connection or file details.

The focused backend checks passed, including request cancellation and temporary-file cleanup. Full Windows regression passed 407 tests with one skip; Linux CI passed 406 tests with two skips. The run record identifies the tested code commit and remaining limits. This is an operational improvement on the way to the MVP; pilot access, C16 catalog/history completion, real model/document quality and recovery validation remain open.
