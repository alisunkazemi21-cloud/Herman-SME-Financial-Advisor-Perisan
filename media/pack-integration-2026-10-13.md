# Consistent package meaning across investigations

Inventory analysis and duplicate checks now use the reviewed package size valid at the event time. New results include the applied factors and sources. A later revision does not rewrite an old analysis or conversation; fresh advice withholds figures whose recorded inputs are stale.

The public catalog-editing workflow remains unfinished. For the first pilots, the proposed service is a weekly review of a few costly ingredients at businesses with usable records. We must measure consistent data delivery, verified actions, paid renewal and actual support effort. No unexplained discrepancy is treated as proven theft or recovered money.
