# Quick questions no longer require inventory data

Quick Advisor now accepts a financial question on its own. A user can also include short document excerpts and explicit financial figures from the current situation. The application does not pull earlier business records or save the conversation in this mode.

When enough figures are supplied, typed calculations can return ratios and cash values with their source references. If a figure is missing, Quick says what is missing; a number appearing in a note is not silently promoted into a calculation. Supplied documents and model explanations remain unverified.

This is milestone **C11** in the [development map](../research/PROGRESS.md). The full software checks passed 226 tests with one real-OCR skip. Real local-model answers and OCR quality still need evaluation. The visible business portfolio screen remains deferred.
